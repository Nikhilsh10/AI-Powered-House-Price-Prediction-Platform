# AI-Powered House Price Prediction Platform

This repository contains an end‑to‑end machine‑learning pipeline for predicting house prices, together with an interactive Streamlit dashboard.

## Project Structure
```
├─ data/
│  ├─ raw/               # Original raw dataset (not tracked in Git)
│  └─ processed/
│     ├─ clean_data.csv  # Processed dataset used by the dashboard
│     └─ feature_metadata.json
├─ models/                # Trained model artifacts and metrics.json
├─ src/
│  ├─ training/          # Training scripts (XGBoost, LightGBM, etc.)
│  ├─ inference/         # Inference utilities
│  ├─ explainability/    # SHAP explainability utilities
│  └─ dashboard/         # Streamlit app (pages, components)
├─ requirements.txt       # Python dependencies for Streamlit Cloud
└─ README.md             # **You are reading it now**
```

## How to Run Locally
```bash
# Install dependencies
pip install -r requirements.txt

# Run the Streamlit dashboard
streamlit run src/dashboard/app.py
```

## Data Availability
- The `data/processed/clean_data.csv` file is required for the **Analytics** page. It is generated by the training pipeline (`src/training/...`).
- If you clone the repo before running the training step, the file will be missing and the dashboard will raise a `FileNotFoundError`.
- **Temporary fix**: A placeholder CSV is included in the repository with the correct column names so the dashboard can load without error.

## Deployment
The app is deployed on Streamlit Community Cloud. Ensure that **all** required libraries are listed in `requirements.txt` (including `joblib`, `shap`, `plotly`, etc.). After pushing any changes, Streamlit Cloud will automatically rebuild the environment.
